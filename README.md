# Python Projects by Lord-Rahul

Welcome to my collection of Python projects! In this repository, you'll find various Python-based applications that I have developed. Each project demonstrates my ability to build real-world applications using Python.

## Projects

### 1. AI Assistant - Freiday
**Description**: Freiday is a simple AI assistant that helps you manage tasks and respond to queries. It is built using Python libraries such as `speech_recognition`, `pyttsx3`, and more.

**Features**:
- Voice recognition and response
- Task management (adding, removing, viewing tasks)
- Search capabilities (Google, Wikipedia, etc.)
  
**Technologies Used**: 
- Python
- `speech_recognition`
- `pyttsx3`
- `wikipedia-api`

### 2. Student Management System
**Description**: A simple student management system that helps manage student records, including adding, updating, and deleting student details.

**Features**:
- Add, edit, delete student records
- View student information
- Search for students based on different criteria

**Technologies Used**:
- Python
- SQLite (for database management)
  
### 3. Library Management System
**Description**: This system is designed to manage books, members, and transactions within a library. It allows for adding books, checking them out, and tracking their status.

**Features**:
- Add, edit, delete books
- Member registration and book checkouts
- Track borrowed books and due dates

**Technologies Used**:
- Python

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Lord-Rahul/Python.git
   ```
2.  Install dependencies:
```
   pip install -r requirements.txt
```
3. Run the desired project by navigating to its folder and executing the Python script.
